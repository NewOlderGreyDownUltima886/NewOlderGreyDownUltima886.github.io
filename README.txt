АКУШЕРСТВО — PWA

В комплекте: 32 карточки, тест из 15 вопросов (10 случайных за попытку), справочник с поиском, отметки «Знаю»/«Повторить», статистика, тёмная тема, сохранение прогресса, офлайн-кэш.

УСТАНОВКА НА ANDROID:
1. Загрузить содержимое папки на статический хостинг с HTTPS (например, GitHub Pages или Netlify).
2. Открыть опубликованную ссылку в Chrome на Android.
3. Выбрать «Установить приложение» или «Добавить на главный экран».
4. После первой загрузки приложение сможет открываться офлайн.

PWA требует HTTPS (либо localhost для тестирования). Для локальной проверки на компьютере можно запустить в папке команду: python -m http.server 8000 и открыть http://localhost:8000.

Числовые значения перенесены из предоставленного конспекта. Это учебный тренажёр, не инструмент для клинических решений; сверяйте нормативы с актуальными источниками и преподавателем.
